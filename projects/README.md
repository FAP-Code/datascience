# Projects

Each subfolder here is one self-contained data science project — either a
replication of existing work or an original analysis. See the repository
root `README.md` and `CLAUDE.md` for how projects are structured and added.

## Index

- [`titanic-survival-prediction/`](titanic-survival-prediction/) — Replication.
  Predicting Titanic passenger survival from class, sex, age, fare, and family
  attributes; benchmarks Logistic Regression, Random Forest, and Gradient
  Boosting via stratified cross-validation.
- [`covid19-vaccine-effectiveness/`](covid19-vaccine-effectiveness/) — Original
  analysis. Did COVID-19 vaccine rollout speed differ by country income level,
  and did higher vaccination coverage predict lower Delta-wave mortality?
  Uses the Our World in Data COVID-19 dataset.
